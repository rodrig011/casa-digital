# Vender

Todo para conseguir clientes por WhatsApp sin depender de nadie.

| Archivo | Para qué |
|---|---|
| [GUIA-DE-VENTA.md](GUIA-DE-VENTA.md) | La guía: rutina diaria, qué contestar a cada respuesta, precio y cómo defenderlo, cuándo mandar video, cómo llevar una llamada y cómo arrancar un cliente con el kit |
| [MENSAJES-LISTOS.md](MENSAJES-LISTOS.md) | Primer mensaje y dos seguimientos para cada negocio de Honduras, con botón que abre WhatsApp con el texto puesto |
| `prospectos_hn.py` | De donde salen los mensajes. `python3 vender/prospectos_hn.py` vuelve a escribir MENSAJES-LISTOS.md |

Los mismos mensajes están cargados en la página de WhatsApp: https://claude.ai/artifact/SUV15bH8BrWtgiokUBPc59. La página manda sobre este archivo si alguna vez no coinciden (ahí se anota a quién ya se le escribió).

Precios: [oferta/PLAN-DE-OFERTA.md](../oferta/PLAN-DE-OFERTA.md).
